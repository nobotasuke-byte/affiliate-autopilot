# Affiliate Autopilot

無料枠を基本に、アフィリエイト記事の作成と品質確認を省力化するためのプロジェクトです。

## 現在の状態
- GitHub リポジトリ：作成済み
- 仮のWebサイト：初期ページのみ
- 記事自動生成：未設定
- 事実確認・品質チェック：運用ルールの準備段階
- 自動公開：未設定
- ASP連携・広告リンク：未設定

## 想定構成
1. Gemini APIで記事案を作成
2. 根拠URL・更新日・広告条件・数値の検証を実施
3. 確認できない記述は保留し、下書きに回す
4. 検証を通過した記事のみ、公開対象として取り扱う
5. GitHub ActionsからCloudflare Pagesに静的サイトを配信する

## 運用上の原則
- APIキー、ログイン情報、ASP認証情報はリポジトリに保存しない
- 料金、報酬単価、キャンペーン、提供条件は最新の一次情報で確認できない限り掲載しない
- 公式ページにアクセスできない場合は「確認済み」としない
- 引用元と確認日を保存する
- 生成AIだけの自己評価を事実確認の代わりにしない
- 広告であることを明示し、広告主・ASPの規約を遵守する
- チェックが未完了の記事は自動公開しない

構築中のため、このリポジトリのコードだけで無人の収益化が実現するわけではありません。
